# 📚 ExamHive24 – WordPress Educational Platform A WordPress-based educational platform designed to organize educational resources and examination-related information in a simple, accessible, and user-friendly environment. ![WordPress](https://img.shields.io/badge/WordPress-CMS-21759B?style=for-the-badge&logo=wordpress&logoColor=white) ![PHP](https://img.shields.io/badge/PHP-Backend-777BB4?style=for-the-badge&logo=php&logoColor=white) ![MySQL](https://img.shields.io/badge/MySQL-Database-4479A1?style=for-the-badge&logo=mysql&logoColor=white) ![JavaScript](https://img.shields.io/badge/JavaScript-Programming-F7DF1E?style=for-the-badge&logo=javascript&logoColor=black) ![CSS3](https://img.shields.io/badge/CSS3-Styling-1572B6?style=for-the-badge&logo=css3&logoColor=white) ## 📖 About the Project **ExamHive24** is a WordPress-based educational website developed to provide students with an organized platform for accessing educational resources and examination-related information. The project demonstrates the use of WordPress as a Content Management System (CMS), supported by PHP, MySQL, HTML, CSS, and JavaScript. It provides a foundation for managing educational content and customizing website functionality through WordPress themes and plugins. The project was developed as a practical implementation of web development and content management technologies. ## 🎯 Project Objectives - Develop a user-friendly educational website. - Organize educational and examination-related resources. - Make learning materials easier to access. - Provide structured website navigation. - Enable content management through the WordPress dashboard. - Apply practical knowledge of WordPress, PHP, and MySQL. - Build a flexible platform that can be extended with additional features. ## ✨ Key Features ### 📚 Educational Resources Provides a foundation for publishing and organizing educational materials, articles, and learning resources. ### 📝 Examination Information Supports the organization of examination-related information and study materials. ### 🗂️ Content Management Uses the WordPress administration dashboard to manage website content and settings. ### 🧭 Easy Navigation Organizes website content into structured sections for convenient browsing. ### 📱 Responsive Interface The website can be customized to support desktop, laptop, tablet, and mobile screens through responsive themes and styling. ### 🎨 Customizable Design Supports design customization using WordPress themes, CSS, and JavaScript. ### 🔌 Plugin Extensibility WordPress plugins can be used to extend the platform's functionality. ## 🛠️ Technologies Used | Technology | Purpose | |---|---| | WordPress | Content management system | | PHP | Server-side functionality | | MySQL | Database management | | HTML5 | Website structure | | CSS3 | Styling and layout | | JavaScript | Client-side interactions | | XAMPP | Local development environment | | Apache | Local web server | ## 🏗️ System Architecture The platform follows a typical WordPress architecture: ```text Student / Visitor | v Web Browser | v Apache Server | v WordPress | +----------+----------+ | | v v Theme / Design Plugins / Features PHP, CSS, JS | | | +----------+----------+ | v MySQL Database ``` ## 💻 Installation and Setup Follow these steps to run the project locally. ### Prerequisites Install the following software: - [XAMPP](https://www.apachefriends.org/) - A modern web browser - Git (optional) ### Step 1: Clone the Repository ```bash git clone https://github.com/MuniraRoma/ExamHive24-Wordpress-Project.git ``` Alternatively, download the repository as a ZIP file from GitHub. ### Step 2: Move the Project Copy the project folder into the XAMPP `htdocs` directory. Example: ```text C:\xampp\htdocs\ExamHive24-Wordpress-Project ``` ### Step 3: Start XAMPP Open the XAMPP Control Panel and start: - Apache - MySQL ### Step 4: Create the Database 1. Open `http://localhost/phpmyadmin/`. 2. Create a MySQL database for the project. 3. Import the provided `examhive24.sql` file into the database. 4. Verify that the database tables have been imported successfully. **Important:** Check the database name and settings inside `wp-config.php`. If that file is not included in the repository, create it from `wp-config-sample.php` and configure the database credentials. ### Step 5: Configure WordPress Update the database settings in `wp-config.php`: ```php define('DB_NAME', 'your_database_name'); define('DB_USER', 'root'); define('DB_PASSWORD', ''); define('DB_HOST', 'localhost'); ``` Use the actual database name and credentials configured on your computer. ### Step 6: Open the Website Visit: ```text http://localhost/ExamHive24-Wordpress-Project/ ``` If the database was imported from an existing WordPress installation, you may also need to update the WordPress site URL and home URL to match your local address. ## 📂 Project Structure ```text ExamHive24-Wordpress-Project/ │ ├── wp-admin/ # WordPress administration ├── wp-content/ # Themes, plugins, and uploads ├── wp-includes/ # WordPress core libraries ├── index.php # Main WordPress entry point ├── wp-config-sample.php # Sample configuration ├── wp-login.php # WordPress login ├── examhive24.sql # Database export ├── .htaccess # Apache configuration ├── .gitignore # Git ignore rules ├── license.txt # WordPress license information └── README.md # Project documentation ``` ## 🔮 Future Improvements Potential future enhancements include: - Student registration and personalized accounts. - Advanced examination and quiz management. - Online assessments and automated result generation. - Searchable educational resources. - Improved mobile accessibility. - Additional security and performance optimizations.
